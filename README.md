# technodekor

Минималистичный адаптивный лендинг «Технодекор» для сайта Технопанель.

## Файлы

- `index.html` — структура страницы
- `style.css` — визуальный стиль и адаптив
- `app.js` — меню, вкладки, модальные формы
- `tilda-brief.md` — краткое ТЗ для переноса в Tilda

## Локальный запуск

```bash
python3 -m http.server 4173
```

Открыть: `http://127.0.0.1:4173/`
